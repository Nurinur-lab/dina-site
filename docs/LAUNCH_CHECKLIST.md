# Чек-лист перед запуском

Сайт полностью собран, проходит проверки качества (см. `PROGRESS.md`, фаза 6) и работает
без данных ниже — но для публикации под реальным именем клуба они нужны.

## От владельца

- [ ] Подтвердить полное название клуба (ИФК или ИСК) → `content/club.json → displayFullName`,
      `nameStatus`, `nameNote`. Пока везде на сайте используется значение из брифа заказчика
      («Императорский футбольный клуб»), с пометкой в коде, что оно ждёт подтверждения.
- [ ] Реквизиты: полное наименование юрлица, ИНН, ОГРН, юридический адрес →
      `content/club.json → requisites`. Пока `null` — страница `/politika` помечена как
      черновик и закрыта от индексации поисковиками (`robots: noindex`) до заполнения.
- [ ] Email для заявок с сайта → `.env → MAIL_TO`, и публичный email/телефон/адрес →
      `content/club.json → contacts`
- [ ] Соцсети клуба (если есть) → `content/club.json → contacts.socials`
- [ ] Выбрать слоган (сейчас «У великих клубов нет финала», варианты — в
      `content/club.json → taglineAlternatives`) → `content/club.json → tagline`
- [ ] Фото: минимум все слоты с `required: true` из `content/photos.json`, с правами на
      использование и указанием автора в поле `credit`. Как добавить — см.
      `docs/CONTENT_GUIDE.md`. До появления фото сайт показывает типографические заглушки —
      это ожидаемое поведение, не баг.
- [ ] SVG-версия логотипа (если есть) — сейчас используется растр `public/brand/logo-full.png`
- [ ] Данные оператора персональных данных для политики конфиденциальности (дублирует пункт
      «Реквизиты» выше)

## Технические

- [ ] VPS у российского провайдера, домен, DNS — пошагово в `docs/DEPLOY.md`
- [ ] SMTP-ящик (Яндекс 360 / VK WorkSpace) → `.env → SMTP_*`. Без него форма работает, но
      письма только пишутся в лог сервера, не отправляются
- [ ] Счётчик Яндекс.Метрики (по желанию) → `.env → NEXT_PUBLIC_YM_ID`. Баннер согласия на
      cookie появится на сайте автоматически, как только это значение будет задано
- [ ] `.env → NEXT_PUBLIC_SITE_URL` — реальный адрес сайта (нужен для корректных
      canonical-ссылок, sitemap.xml и Open Graph превью)
- [ ] Уведомление в Роскомнадзор об обработке персональных данных (если клуб ещё не подавал)
- [ ] После деплоя — проверить `/sitemap.xml` и `/robots.txt` на реальном домене, и при
      желании отправить sitemap в Яндекс.Вебмастер / Google Search Console
