# Чек-лист перед запуском

Сайт собирается и работает без этих данных, но для публикации они нужны.

## От владельца
- [ ] Подтвердить полное название клуба (ИФК или ИСК) → `content/club.json`
- [ ] Реквизиты: полное наименование юрлица, ИНН, ОГРН, юридический адрес → `content/club.json → requisites`
- [ ] Email для заявок с сайта → `.env → MAIL_TO`, и публичный email/телефон → `content/club.json → contacts`
- [ ] Соцсети клуба (если есть) → `content/club.json → contacts.socials`
- [ ] Выбрать слоган (сейчас «У великих клубов нет финала») → `content/club.json → tagline`
- [ ] Фото: минимум все слоты с `required: true` из `content/photos.json`, с правами на использование и указанием автора
- [ ] SVG-версия логотипа (если есть)
- [ ] Данные оператора персональных данных для политики конфиденциальности

## Технические
- [ ] VPS у российского провайдера, домен, DNS
- [ ] SMTP-ящик (Яндекс 360 / VK WorkSpace)
- [ ] Счётчик Яндекс.Метрики (по желанию)
- [ ] Уведомление в Роскомнадзор об обработке персональных данных (если клуб ещё не подавал)
