# Сайт ИФК «Дина»

Стартовый комплект для разработки с Claude Code.

- `CLAUDE.md` — правила проекта, стек, дизайн-система, фазы работы
- `START_PROMPT.md` — первое сообщение для Claude Code
- `SETUP.md` — как запустить проект в терминале
- `content/` — проверенный контент (факты, тексты, фотослоты, источники)
- `docs/research-notes.md` — исследование и расхождения в источниках
- `docs/LAUNCH_CHECKLIST.md` — что нужно собрать до публикации
- `.claude/settings.json` — разрешения для автономной работы
